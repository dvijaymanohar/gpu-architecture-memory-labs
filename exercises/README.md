# Exercises

- Print block/thread/warp IDs for a small launch and draw the mapping.
- Modify the stride benchmark and predict coalescing behavior before running.
- Write a shared-memory tiled reuse kernel and compare global traffic.
- Create a bank-conflict case and remove it.
- Sweep block sizes and explain occupancy/runtime changes.
- Compare FP32 with FP16/BF16 storage and validate numerical differences.
